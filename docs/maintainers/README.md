# Maintainer handbook

Project mechanics that are not part of the product contract live here.

- [`repository-settings.md`](repository-settings.md) — GitHub settings, labels, rulesets, security features, and milestones that cannot be expressed completely as repository files.
- [`release-process.md`](release-process.md) — release-quality checklist for future signed/notarized builds.

Keep these documents practical. If a maintenance rule becomes an architectural requirement for SpaceDress itself, move the decision into an ADR or product documentation.
