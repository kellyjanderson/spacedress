# Research notes

This directory holds evidence about macOS behavior that is not guaranteed by a public Apple API.

Research is allowed to be provisional. Architecture is not.

Before turning an observation here into a project invariant, either establish a supported platform contract or record the deliberate dependency and failure strategy in an ADR.

Current documents:

- [`macos-integration.md`](macos-integration.md) — integration tiers and feasibility baseline;
- [`prior-art.md`](prior-art.md) — open-source projects worth studying.

Future experiment notes should record macOS build, hardware, display topology, Mission Control settings, permissions, SIP state, procedure, raw observation, interpretation, confidence, and next falsifying test.
